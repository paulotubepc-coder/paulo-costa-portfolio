PORTFÓLIO PROFISSIONAL — PAULO COSTA

ARQUIVOS
- index.html: estrutura e conteúdo do site.
- style.css: identidade visual e layout responsivo.
- script.js: menu mobile, tema claro/escuro e animações.
- assets/paulo-costa.jpg: fotografia utilizada no cabeçalho.

COMO VISUALIZAR
1. Extraia o arquivo ZIP.
2. Abra a pasta paulo_costa_portfolio.
3. Dê dois cliques em index.html para abrir no navegador.

COMO PUBLICAR NO GITHUB PAGES
1. Entre no GitHub e abra o repositório que será usado para o site.
2. Envie todos os arquivos e a pasta assets (não envie apenas o ZIP).
3. No repositório, abra Settings > Pages.
4. Em Build and deployment, selecione Deploy from a branch.
5. Escolha a branch main e a pasta / (root), depois clique em Save.
6. Aguarde a publicação e acesse o endereço informado pelo GitHub Pages.

OBSERVAÇÕES
- O site não contém currículo PDF porque o arquivo ainda não foi fornecido/criado.
- Os textos dos projetos estão em formato de resumo. Podemos acrescentar resultados, imagens e estudos de caso quando você fornecer exemplos concretos.
- Os links de e-mail, WhatsApp e LinkedIn já estão configurados.
